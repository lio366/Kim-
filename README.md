## 🚀 Instalación

### Requisitos
- Cuenta Railway (gratis)
- Cuenta Groq (gratis, 1M tokens)
- Cuenta Stripe (gratis)
- Dominio (opcional, $12/año)

### Pasos
```bash
# 1. Clonar
git clone https://github.com/tu-usuario/kimi-os.git
cd kimi-os

# 2. Configurar variables
cp .env.example .env
# Editar .env con tus credenciales

# 3. Deployar en Railway
railway login
railway init
railway up

# 4. Listo
# La IA empieza a trabajar sola
```
